# CodeAlpha_Calculator

A responsive calculator built with HTML, CSS and JavaScript as part of my CodeAlpha Frontend Development internship (Task 2).

## Features
- Addition, subtraction, multiplication and division
- Clear (AC), delete, percent and sign toggle
- Real-time display with calculation history
- Full keyboard support
- Division by zero handling
- Responsive dark UI

## Keyboard Shortcuts
| Key | Action |
|---|---|
| 0-9, . | Input numbers |
| + - * / | Operators |
| Enter or = | Calculate |
| Backspace | Delete last digit |
| Esc | Clear |

## Run Locally
Open `index.html` in any browser.
